올인원 마크다운 스크래치패드 & 텍스트 유틸리티

실시간 마크다운 미리보기 · 대소문자 변환 · 스마트 조편성 · 세계 시차 계산

1. 내용 입력

선택한 날짜의 IANA 표준 시간대 DB를 기반으로 현지 썸머타임(EDT/EST 등)을 자동 연산합니다.

2. 결과 미리보기

🧮 핵심 원리 및 데이터 보안

  • 마크다운 파서: 입력 텍스트를 먼저 철저히 이스케이프한 뒤 제목, 강조, 코드, 목록, 인용구, 링크만 규격 렌더링하여 XSS 스크립트 실행을 원천 방어합니다.
  • 케이스 변환: 공백, 기호, 대소문자 전환 지점을 정규식으로 감지하여 프로그래밍 식별자 규격으로 정밀 변환합니다.
  • 암호학적 랜덤 셔플: crypto.getRandomValues를 활용한 Fisher-Yates 알고리즘으로 완전 무작위 공정 배정을 보장합니다.
  • 세계 시차 계산: 브라우저 내장 Intl.DateTimeFormat API와 IANA 데이터베이스를 연동해 썸머타임 전환(gap/overlap)까지 완벽 대응합니다.
  • 읽기 소요 시간: 한국어 묵독 기준 분당 500자(영문 238단어) 통계를 기준으로 소요 시간을 추정합니다.

데이터 보안 원칙: 모든 연산과 메모는 사용자 기기의 브라우저 내부에서만 실행되며 외부 서버로 절대 전송되지 않습니다.

❓ 자주 묻는 질문 (FAQ)

작성 중인 마크다운 메모는 안전하게 자동 저장되나요?

네, 사용 중인 브라우저의 로컬 저장소(LocalStorage)에만 안전하게 보관됩니다. 새로고침을 하거나 창을 닫아도 복원되며, 외부 서버로는 단 1글자도 전송되지 않습니다. '내용 비우기'를 누르면 즉시 삭제되며 바로 되돌릴 수 있습니다.

어떤 마크다운 문법이 지원되나요?

제목(#~######), 굵게(**), 기울임(*), 취소선(~~), 인라인 코드 및 다중 행 코드 블록, 글머리 기호 목록, 번호 매기기 목록, 체크박스 작업 목록, 인용구(>), 구분선(---), 그리고 안전한 http/https 링크가 지원됩니다. 원본 HTML 태그는 모두 텍스트로 안전하게 변환되어 악성 스크립트 실행이 차단됩니다.

랜덤 조편성은 조작 없이 공정하게 추첨되나요?

웹 표준 암호화 난수 생성기(crypto.getRandomValues)와 검증된 Fisher-Yates 셔플 알고리즘을 사용하여 팀원 명단을 완벽하게 무작위 셔플한 뒤 각 팀에 순차 분배합니다. 모든 팀의 인원수 차이는 최대 1명 이내로 균등 배정됩니다.

세계 시차 계산 시 썸머타임(서머타임)이 반영되나요?

선택한 날짜와 시간에 맞춰 브라우저 내장 IANA 표준 시간대 데이터베이스를 조회하여 뉴욕(EDT/EST), 런던(BST/GMT) 등의 일광 절약 시간제 변동을 정확하게 자동 반영합니다.

사내 기밀이나 회의 메모가 외부로 유출될 위험은 없나요?

본 유틸리티는 100% 클라이언트 브라우저 메모리 안에서만 동작하는 순수 정적 웹앱입니다. 별도의 백엔드 데이터베이스나 외부 전송 API가 전혀 존재하지 않으므로 사내 보안 환경에서도 안심하고 사용할 수 있습니다.
