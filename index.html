자주 묻는 질문 (FAQ)

작성한 마크다운 문서가 새로고침해도 유지되나요?

네. 브라우저의 LocalStorage에 키스트로크마다 자동 저장되므로 예기치 않게 탭을 닫거나 새로고침해도 직전 작업 내용이 완벽히 복구됩니다.

랜덤 조편성은 공정하게 무작위로 추첨되나요?

수학적으로 검증된 Fisher-Yates 셔플 알고리즘을 사용하여 참가자 전원에게 100% 균등한 확률의 무작위 팀 분배를 보장합니다.

사내 보안 문서를 변환기에 붙여넣어도 안전한가요?

본 도구는 외부 API 서버로 데이터를 일절 전송하지 않는 100% 클라이언트사이드 순수 자바스크립트 엔진입니다. 사내 기밀 보고서나 코드를 안전하게 가공할 수 있습니다.

마크다운 프리뷰에서 표(Table)나 체크박스도 지원하나요?

네, GitHub Flavored Markdown(GFM) 규격을 완벽 지원하여 표, 체크리스트, 취소선, 인라인 코드블록 등을 모두 깔끔한 다크모드 테마로 실시간 렌더링합니다.

세계 시간대 계산 시 서머타임(Daylight Saving)이 자동으로 반영되나요?

네. 브라우저의 표준 Intl 및 IANA 타임존 데이터베이스(Asia/Seoul, America/New_York, Europe/London 등)를 사용하여 계절별 일광절약시간제(서머타임)가 1초의 오차 없이 자동 계산됩니다.
